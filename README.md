# Owlbear Image Effects

A simple Owlbear Rodeo extension.
- Made for personal campaign; may be used, edited, forked, however if you'd like.

Features:
- Grayscale maps
- Increase contrast/sharpness
- Toggle per layer

Install:
Add this manifest URL:
